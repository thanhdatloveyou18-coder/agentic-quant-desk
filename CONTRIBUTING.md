# Contributing to Agentic Quant Desk

We welcome contributions to the **Agentic Quant Desk** project! Whether you're reporting a bug, proposing a new feature, or submitting a pull request, we appreciate your help in building a safer, more transparent quantitative trading framework.

## How to Contribute

1. **Fork the Repository**: Create your own branch from `main`.
2. **Set Up Development Environment**:
   ```bash
   git clone https://github.com/thanhdatloveyou18-coder/agentic-quant-desk.git
   cd agentic-quant-desk
   pip install -e .
   ```
3. **Run Tests**:
   ```bash
   python -m unittest discover tests
   ```
4. **Submit a Pull Request**:
   - Ensure all unit tests pass.
   - Describe the changes made and the motivation.
   - Follow PEP 8 style guidelines.

## Code of Conduct
We are committed to providing a welcoming, inclusive, and harassment-free environment for everyone.
